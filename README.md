# 荔枝镜头 · LitchiLens

面向活动照片临时分享的轻量相册：手机浏览，免账号登录，优先下载 JPG，可选下载 NEF 原片，通过 IPv6 和端口直接访问。

## 当前状态

项目初始化阶段，已确定需求与开发约定，尚未实现相册、照片导入或部署功能。

## 使用场景

- 约 3000 多张军训照片，供 300 多名同学访问。
- 自有 Linux 服务器，家庭上行带宽约 60 Mbps。
- 网站开放几天至几周，无域名，使用 IPv6 地址和独立 HTTPS 端口。
- 访问者无需注册或登录，通过分享链接或二维码访问。

## 首版计划

1. 清点照片，按目录和文件名配对 JPG 与 NEF，并报告歧义和缺失项。
2. 离线生成缩略图、预览图和相册索引，保留原始文件。
3. 提供中文手机相册，支持分组浏览、懒加载、大图查看。
4. 默认下载高清 JPG，对存在的 NEF 提供独立下载按钮与大小提示。
5. 使用 Nginx 分发文件，配置缓存与下载并发限制。
6. 配置 IPv6 IP 证书、自动续期和 HTTPS 校验，生成分享二维码。

首版以静态页面、JSON 索引和 Nginx 为基础，不引入账号数据库。具体处理工具待照片样本确认后选择。

## 人脸检索候选功能

先用少量代表照片评估“点选一张照片中的脸，寻找可能匹配的其他照片”。是否加入首版尚未确定。

- 不关联姓名、学号，不将匹配结果视为身份确认。
- 不要求上传自拍，保留普通分组浏览方式。
- 开放前向参与者说明用途；免登录无法限制访问者只搜索自己。
- 人脸特征留在自有服务器，服务结束后清理索引。

## 网络与数据边界

- 纯 IPv6 服务需要访问者的网络支持 IPv6。
- IPv6 地址变化后，即使证书自动更新，旧分享链接仍需替换。
- 随机分享路径用于减少偶然访问，不等同于身份认证；链接可以被转发。
- 照片、人物索引、证书、私钥、密码和真实服务器配置均不进入 Git。
- 上线前验证手机浏览、下载、外网访问、证书续期及现有站点不受影响。
